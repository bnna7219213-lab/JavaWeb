后端(Spring Boot)提供数据和业务 API，浏览器通过加载 .wasm 模块执行近原生速度的计算密集型逻辑。 WASM 字节码在浏览器内以接近本地机器码的速度运行，相比纯 JavaScript 通常有 1.5x-3x 的性能提升。
