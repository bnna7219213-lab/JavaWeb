Astro 岛屿架构 (Islands Architecture)

默认零 JS 静态渲染 + 局部交互水化

零 JS 默认

服务端直接渲染 HTML，首屏无需加载任何 JavaScript

按需水化

仅在需要交互的区域（岛屿）加载并执行 JS

极致性能

首屏 FCP < 1s，Lighthouse 评分接近满分

ISLAND Alpine.js 折叠面板

岛屿架构核心原理

  • 服务端渲染所有静态内容（HTML）
  • 在 HTML 中标记需要交互的"岛屿"区域
  • 客户端运行时仅水化这些岛屿组件
  • 其余部分保持纯静态 HTML，零运行时开销
 Astro 语法示意：
---
// 服务端代码（在服务端执行）
const users = await fetch('/api/users').then(r => r.json());
---
<!-- 静态内容（服务端渲染） -->
<h1>用户列表</h1>
{#each users as user}
  <p>{user.name}</p>
{/each}

<!-- 交互岛屿（客户端水化） -->
<Search client:load />

ISLAND Alpine.js Tab 切换

使用 Thymeleaf 模板引擎在服务端渲染 HTML，页面加载时已经包含完整内容。浏览器只需要解析 HTML + CSS 即可显示。

Alpine.js 只在水化特定"岛屿"组件时加载执行。其他静态区域完全不参与 JS 引擎的解析执行，大幅减少客户端负担。
