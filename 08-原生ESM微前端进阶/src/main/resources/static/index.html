应用注册表

  • 动态发现 - 从 /api/apps 加载应用清单
  • 按需加载 - 点击 Mount 才下载子应用代码
  • 配置集中 - entry、containerId、version 统一管理

生命周期管理

  • mount - 下载模块 + 渲染 + 注册事件
  • unmount - 卸载 React + 清理监听 + 释放内存
  • reload - 卸载后重新挂载，模拟独立部署

子应用通信

  • 事件总线 - Publish/Subscribe 解耦
  • 跨域支持 - CustomEvent + window 对象传递
  • 命名空间 - source.eventName 格式规范
