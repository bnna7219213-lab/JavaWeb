什么是SCS?

Self-Contained System 是一种微服务架构风格，核心理念是：

  • 一个服务 = 一个完全自包含的系统单元
  • 每个SCS有自己的后端、数据库、前端
  • 能独立运行、独立部署
  • 服务间通过异步消息通信
  • 每个SCS有明确的限界上下文

本SCS单元: 用户服务

自有前端

同一jar内的Thymeleaf模板，路径: /user/

自有API

RESTful接口，路径: /api/v1/users

自有数据库

模拟的独立数据存储，完全隔离

自有消息

Spring Events + Message Broker模拟

  3. 访问 消息监控 查看消息流转
