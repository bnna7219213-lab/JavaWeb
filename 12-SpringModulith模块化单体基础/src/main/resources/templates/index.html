Spring Modulith 模块化单体基础版

基于 Spring Boot 3.3 + JDK 21 的模块化架构

首页 用户管理 商品管理 订单管理

模块化架构概述

本项目演示了如何使用 Spring Boot 构建模块化单体应用。

系统分为三个独立模块，每个模块有清晰的边界和对外接口。

模块结构

User 模块

用户管理

  • UserEntity (内部)
  • UserService (内部)
  • UserModule (对外API)
  • UserController

Product 模块

商品管理

  • ProductEntity (内部)
  • ProductService (内部)
  • ProductModule (对外API)
  • ProductController

Order 模块

订单管理（跨模块通信）

  • OrderEntity (内部)
  • OrderService (内部)
  • OrderModule (对外API)
  • OrderController
  • → 引用 UserModule 接口
  • → 引用 ProductModule 接口

设计原则

接口隔离

模块通过 *Module 接口对外暴露功能，禁止直接访问实体类

依赖倒置

OrderService 依赖 UserModule / ProductModule 接口，而非具体实现

封装性

Entity 和内部 Service 不对外暴露，跨模块通信走 API

事件驱动

模块使用 ApplicationEvent 解耦通信（OrderEvent, UserEvent）
