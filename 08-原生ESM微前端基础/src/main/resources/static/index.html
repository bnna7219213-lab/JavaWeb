架构核心机制

  • Import Maps：集中声明 react、react-dom 等共享依赖解析路径
  • 动态 import()：Host App 通过 import('/microapp/app1/main.js') 懒加载子应用
  • 生命周期协议：子应用必须导出 mount(container) / unmount() 接口
  • postMessage 通信：主子应用通过 window.postMessage 传递数据
  • 零构建：无需 Webpack/Vite/Rollup，纯原生 ES Module 直接运行
