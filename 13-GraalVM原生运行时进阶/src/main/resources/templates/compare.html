Use Case Recommendations

AWS Lambda

Use Native Image

Cold start is critical. Native Image cold start is 50-200ms vs JVM's 5-15s.

Kubernetes Microservices

Use Native Image

Fast pod start, low memory, high density per node.

High Throughput APIs

JVM May Be Better

JVM JIT achieves slightly higher peak throughput after warmup.

Batch Processing

Evaluate Both

Short-lived: Native wins. Long-running: JVM JIT may optimize better.

CLI Tools

Use Native Image

Instant startup, single binary distribution, no JVM dependency.

Legacy Integration

JVM Likely

Some legacy libraries don't support native image compilation easily.
