事件监听器实现

// NotificationServiceImpl.java

@EventListener
void onOrderCreated(OrderEvent event) {
    if ("ORDER_CREATED".equals(event.getEventType())) {
        notifyUser(event.getUserId(), "订单已创建");
    }
}

@EventListener
void onUserCreated(UserEvent event) {
    sendWelcomeEmail(event.getUserName());
}

Notification 模块不知道 OrderService 的存在！它只关心事件类型和事件数据。
