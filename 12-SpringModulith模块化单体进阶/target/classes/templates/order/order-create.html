创建订单后的连锁反应

  1. OrderServiceImpl 调用 UserModule.getUser() 验证用户
  2. OrderServiceImpl 调用 ProductModule.getProduct() 获取商品
  3. OrderServiceImpl 调用 ProductModule.reduceStock() 扣减库存
  4. OrderServiceImpl 发布 OrderEvent.created
  5. NotificationServiceImpl 通过 @EventListener 接收事件 → 生成通知
  6. AuditServiceImpl 通过 @EventListener 接收事件 → 记录审计日志

提交后请前往「通知中心」和「审计日志」查看事件驱动的跨模块效果。
