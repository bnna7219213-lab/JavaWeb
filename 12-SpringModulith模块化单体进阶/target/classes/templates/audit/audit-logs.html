审计工作流

用户创建订单:
  1. User Module → 发布 USER_CREATED
  2. Order Module → 发布 ORDER_CREATED / ORDER_COMPLETED
  3. Notification Module → @EventListener → 生成通知
  4. Audit Module → @EventListener → 记录审计日志

审计模块优势:
  ✅ 无需修改业务模块代码
  ✅ 100% 事件覆盖（不遗漏任何操作）
  ✅ 可后续添加审计规则/告警等
