Spring Modulith 模块化单体进阶版

基于 Spring Boot 3.3 + JDK 21 | 五模块 + 事件驱动 + DIP

首页 用户管理 商品管理 订单管理 通知中心 审计日志

进阶版架构概览

相比基础版，进阶版新增Notification和Audit模块，通过事件驱动实现完全解耦的跨模块通信。

五模块架构

User

基础模块

用户管理
无依赖

UserEvent.created UserEvent.deactivated

Product

基础模块

商品管理
无依赖

Order

上游模块

订单管理
依赖 User + Product 接口

OrderEvent.created OrderEvent.completed OrderEvent.cancelled

Notification

事件驱动

通知服务
监听 OrderEvent + UserEvent

@EventListener

Audit

事件驱动

审计服务
监听 OrderEvent + UserEvent

@EventListener

事件驱动通信机制

┌──────────────────────────────────────────────────────────────────────┐
│                    Spring Application Context                          │
│                                                                       │
│   ┌─────────┐ created/deactivated   ┌──────────────┐                  │
│   │  User   │ ──── UserEvent ──────→│ Notification │                  │
│   │ Module  │ ──────────────────→   │   (监听)      │                  │
│   │ (发布)   │ ──────────────────→   │    Audit     │                  │
│   └─────────┘                       │   (监听)      │                  │
│                                      └──────────────┘                  │
│   ┌─────────┐ created/completed/     ┌──────────────┐                  │
│   │  Order  │ cancelled   ──────────→│ Notification │                  │
│   │ Module  │ ──── OrderEvent ──────→│   (监听)      │                  │
│   │ (发布)   │ ──────────────────→   │    Audit     │                  │
│   └─────────┘                       │   (监听)      │                  │
│        ↑                            └──────────────┘                  │
│        │ DIP接口依赖                                                 │
│        │                                                              │
│   ┌────┴──────┐    ┌──────────┐                                      │
│   │   User    │    │ Product  │                                      │
│   │  Module   │    │  Module  │                                      │
│   │  (接口)    │    │  (接口)   │                                      │
│   └───────────┘    └──────────┘                                      │
└──────────────────────────────────────────────────────────────────────┘

关键：Notification 和 Audit 完全不知道 Order/User 的存在。 它们只通过 @EventListener 接收事件，实现零耦合通信。 新增监听者时，源模块代码无需任何修改。

依赖倒置（DIP）完整示意图

OrderServiceImpl 构造器注入:
  ┌─────────────────────────────────────────────┐
  │ OrderServiceImpl                             │
  │  - userModule: UserModule (接口)             │
  │  - productModule: ProductModule (接口)       │
  │  - eventPublisher: ApplicationEventPublisher │
  └─────────────────────────────────────────────┘
           ↑                      ↑
     Spring注入                Spring注入
           │                      │
  ┌────────┴─────────┐  ┌────────┴──────────┐
  │ UserServiceImpl  │  │ ProductServiceImpl │
  │ (implements      │  │ (implements        │
  │  UserModule)     │  │  ProductModule)    │
  │                  │  │                    │
  │ 位于 internal 包  │  │ 位于 internal 包    │
  └──────────────────┘  └────────────────────┘

优势：UserServiceImpl 将来可替换为 RemoteUserModuleImpl（通过Feign/HTTP），
      OrderServiceImpl 代码完全不需要修改。
